# Git 배포 자동화 규칙

## 필수 원칙
- **작업 완료 후 반드시 Git main 브랜치에 커밋 및 푸시(배포)**:
  - 코드 수정, 기능 구현, 버그 수정 등 모든 사용자 요청 작업을 완료하고 검증(빌드/타입 체크)한 후, 반드시 변경된 파일들을 Git에 커밋하고 `origin main` 브랜치로 푸시(배포)해야 합니다.
  - 커밋 메시지는 작업 내용을 명확하게 설명하는 한국어 또는 영어 메시지를 작성합니다.
  - 커밋 후 `git push origin main` 명령어를 실행하여 원격 저장소에 배포를 완료합니다.
