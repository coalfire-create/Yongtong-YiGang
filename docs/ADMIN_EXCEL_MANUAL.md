# 📊 영통 이강학원 관리자 엑셀 일괄 등록 및 브로셔/시간표 수정 매뉴얼

본 매뉴얼은 관리자 페이지에서 **엑셀 파일(`.xlsx`, `.xls`)**을 활용하여 선생님 목록, 정규 시간표, 썸머스쿨 안내 및 시간표, 수강예약/신청 내역을 한 번에 일괄 등록(가져오기)하는 방법과 **개강일, 수업시간, 브로셔(커리큘럼) 세부 내용을 내부에서 수정하는 방법**을 안내합니다.

## 1. 기능 개요 및 접속 방법

### 🔹 관리자 페이지 접속
1. 브라우저에서 `/admin` 주소로 접속합니다.
2. 관리자 비밀번호를 입력하여 로그인합니다.

### 🔹 엑셀 일괄 등록의 장점
- 수십 ~ 수백 개의 데이터를 매번 웹 화면에서 하나씩 입력할 필요 없이 **엑셀 파일 하나로 일괄 추가**할 수 있습니다.
- 학원 시스템에 최적화된 **[엑셀 양식 다운]** 버튼을 통해 정확한 서식을 다운로드하여 작성할 수 있습니다.

## 2. 탭별 엑셀 일괄 등록 방법

### 2-1. 선생님 관리 탭
- **위치**: 좌측 사이드바 → **[인물 및 수업]** → **[선생님 관리]**
- **기능**: 여러 명의 강사 프로필(이름, 소속, 과목, 약력/한줄소개)을 일괄 추가
- **사용 방법**:
  1. 상단 안내 박스의 **[엑셀 양식 다운]** 버튼을 클릭하여 `선생님_일괄등록양식.xlsx` 파일 다운로드
  2. 다운받은 엑셀 파일의 `이름`, `소속`(고등관/초/중등관), `과목`, `한줄소개` 작성
  3. **[엑셀 일괄 등록]** 버튼을 클릭하여 작성한 엑셀 파일 선택
  4. 등록 완료 안내 창 및 리스트 갱신 확인

---

### 2-2. 정규 시간표 관리 탭
- **위치**: 좌측 사이드바 → **[인물 및 수업]** → **[정규 시간표]**
- **기능**: 개강 강좌 및 시간표(구분, 과목, 학교, 강좌명, 강사명, 수업시간, 개강일, 상세설명) 일괄 등록
- **사용 방법**:
  1. 상단의 **[엑셀 양식 다운]** 버튼을 클릭하여 `정규시간표_일괄등록양식.xlsx` 다운로드
  2. 과목명, 강사명, 수업시간, 개강일 등 서식에 맞추어 작성 (강사명이 등록되어 있으면 해당 강사 프로필 사진 자동 연결)
  3. **[엑셀 일괄 등록]** 버튼을 통해 파일 업로드
  4. 홈페이지 노출 및 과목별 필터링이 자동으로 적용됩니다.

---

### 2-3. 썸머스쿨 관리 탭
- **위치**: 좌측 사이드바 → **[특강 및 설명회]** → **[썸머 관리]**
- **기능**:
  - **커리큘럼/가이드라인**: 강사별 썸머스쿨 강좌 상세 및 세부 안내 일괄 등록 (가로형 표 및 시트별 세로형 강사 원본 양식 모두 자동 지원)
  - **시간표(슬롯)**: 요일별 썸머스쿨 시간표 행(오전/점심/오후 등) 일괄 추가
- **사용 방법**:
  - 탭 상단의 **[엑셀 양식 다운]** 후 작성하여 **[엑셀 일괄 등록]** 실행

---

### 2-4. 수강예약 / 레벨테스트 / 문자수신 신청 탭
- **위치**: 좌측 사이드바 → **[수강예약 관리]**, **[수학레벨테스트]**, **[문자 수신]**
- **기능**: 구글 시트, 외부 폼, 기존 장부의 신청자 목록 데이터를 DB로 일괄 복원/가져오기
- **사용 방법**:
  1. 각 신청 관리 화면 우측 상단의 **[양식 다운]** 클릭
  2. 학생명, 연락처, 학교/학년 등 정보 작성
  3. **[엑셀 가져오기]** 버튼 클릭 후 작성 파일 업로드
  4. 기존 신청 목록에 일괄 추가되어 조회 및 관리 가능

## 3. 주요 엑셀 양식 컬럼 명세

| 구분 | 필수 여부 | 추천 입력값 및 입력 예시 | 비고 |
| :--- | :---: | :--- | :--- |
| **선생님 - 소속** | 필수 | `고등관`, `초/중등관` | 미입력 시 고등관 기본 |
| **선생님 - 과목** | 필수 | `국어`, `수학`, `영어`, `과학`, `입시/컨설팅` | 카테고리 분류 |
| **시간표 - 구분** | 필수 | `고등관-고1`, `고등관-고2`, `고등관-고3`, `중등관-중3`, `초/중등관` | 홈페이지 학년탭 매핑 |

## 4. 자주 묻는 질문 및 오류 해결 (FAQ)

### Q1. "엑셀에서 등록할 강좌를 찾지 못했습니다" 오류가 떠요.
- 엑셀 파일의 헤더(첫 번째 줄) 열 이름이 **양식 파일의 제목과 일치**하는지 확인해 주세요.
- 시트 내에 데이터가 첫 번째 행부터 제대로 입력되어 있는지 확인해 주세요.

### Q2. 선생님 사진이나 상세보기 이미지도 엑셀로 올라가나요?
- 이미지 파일(사진)은 보안 및 용량 문제로 엑셀 내부 텍스트로 처리되지 않습니다.
- 엑셀로 강좌/선생님 텍스트 정보를 등록한 후, **관리자 화면의 [사진 관리] 또는 [수정] 버튼**을 통해 이미지를 등록/변경하시면 됩니다.

### Q3. 기존에 있던 시간표가 지워지고 새로 올라가나요?
- **아닙니다!** 엑셀 일괄 등록은 기존 데이터를 삭제하지 않고 **신규 항목으로 추가(Append)**됩니다.
- 기존 데이터를 초기화하고 다시 올리시려면 삭제 버튼을 사용하거나, 썸머시간표의 경우 **[데이터 초기화 (리셋)]** 후 업로드해 주세요.

## 5. 개강일, 수업시간 및 브로셔/커리큘럼 내부 수정 방법

개강일이나 수업시간이 변경되거나 브로셔/커리큘럼 안내 내용을 내부에서 수정해야 할 때 다음 두 가지 방법으로 간단히 변경할 수 있습니다.

### 5-1. 관리자 화면에서 직접 수동 수정하기 (개별 1~2개 강좌 변경 시 추천)

1. **정규 시간표 / 개강일 / 수업시간 수정**:
   - 관리자 페이지 → **[정규 시간표]** 탭 접속
   - 수정하려는 강좌 카드의 ✏️ **[수정] (연필 아이콘)** 버튼 클릭
   - `수업시간` (예: `토/일 14:00~17:00`), `개강일` (예: `3/2(월) 개강`), `수업 설명` 항목의 텍스트를 수정한 후 **[저장]** 클릭
   - 저장 즉시 홈페이지 사용자 화면에 실시간 반영됩니다.

2. **브로셔 / 상세 커리큘럼 내용 수정**:
   - 관리자 페이지 → **[특강 및 설명회]** → **[썸머 관리]** (또는 해당 학년 관리) 탭 접속
   - **[커리큘럼 및 가이드라인]** 목록에서 수정하고자 하는 강좌 항목의 ✏️ **[수정]** 버튼 클릭
   - 편집 폼에서 **수업일정, 강좌특징, 교재/제공자료, 과제/테스트, 관리시스템, 회차별 내용** 등 브로셔 세부 항목 텍스트를 수정한 후 **[저장]** 클릭

---

### 5-2. 엑셀 수정을 통한 일괄 업데이트 방법 (여러 강좌가 대거 변경된 경우)

1. 수정할 학년/분류의 **[엑셀 양식 다운]** 또는 기존 엑셀 파일 열기
2. 엑셀 파일 내에서 변경된 **개강일, 수업시간, 강좌특징, 회차** 텍스트를 올바르게 수정 후 저장
3. 기존에 웹에서 잘못 입력된 강좌는 🗑️ **[삭제]** 버튼으로 지우거나, 엑셀 일괄 등록을 실행하여 최신 정보로 새로 추가
4. **[엑셀 일괄 등록]** 버튼을 통해 수정된 엑셀 파일 업로드
