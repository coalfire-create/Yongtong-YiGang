## 이 폴더 갱신 원칙

- 이 폴더는 git에 커밋되어 GitHub에 그대로 올라갑니다. **비밀번호, API 키, 토큰 등 실제 값은 절대 적지 마세요.** "어디서 확인하는지"만 적습니다.
- 코드나 인프라에 구조적인 변경이 생기면(새 환경변수, 새 배포 대상, 테이블 구조 변경 등) 01번 매뉴얼도 같이 업데이트해 주세요.
