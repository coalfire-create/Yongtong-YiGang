# [마케팅 부서] 페르소나 A 아웃리치 · SEO · 콘텐츠 전략

## 1. 타겟 요약
- 원생 100~300명 규모 보습·입시학원 원장(주로 40대)
- 현재 네이버 블로그 또는 SNS만 운영, 자체 홈페이지 없음
- 의사결정: 원장 1인, 빠른 결정 가능 / 트리거: 경쟁 학원의 온라인 강화, 학부모의 "체계 없어 보인다" 피드백

## 2. 콜드 아웃리치 메시지 (문자·카카오톡용, 단문)
> 안녕하세요 원장님, 영통이강입니다.
> 요즘 학부모님들이 학원 등록 전 꼭 온라인으로 먼저 검색해보신다는 거 알고 계실 텐데요,
> 블로그만으로는 전달하기 어려운 '커리큘럼·강사진·학부모 후기'를 한 번에 보여주는 학원 홈페이지, 2주면 만들어드립니다.
> 부담없이 샘플 페이지 먼저 보여드려도 될까요? 😊

## 3. 콜드 이메일 스크립트 (장문)
**제목:** 학부모님이 "이 학원 믿을 만하네"라고 느끼게 하는 방법

**본문 구성:**
1. 후크: "전단지를 보고 학원명을 검색했는데 아무것도 안 나오면, 학부모님은 5초 만에 다른 학원을 찾습니다."
2. 문제 제기: 블로그만으로는 커리큘럼·강사 전문성·후기를 체계적으로 전달하기 어렵다는 점
3. 해결 제시: 2주 완성 학원 홈페이지 패키지 — 커리큘럼/강사소개/후기게시판/상담신청폼 포함
4. 신뢰 근거: "사교육비 시장은 매년 커지고 있고(2024년 29.2조원), 그만큼 학부모의 학원 비교도 꼼꼼해지고 있습니다."
5. CTA: "3분이면 확인 가능한 샘플 데모 페이지를 보내드릴까요?"

## 4. 랜딩페이지 카피 (자사 영업용 페이지)
- **헤드라인:** "블로그만으로는 안 보이던 것, 학원 홈페이지로 채우세요"
- **서브카피:** "커리큘럼, 강사진, 학부모 후기까지 — 학부모가 등록을 결정하는 데 필요한 모든 정보를 한 페이지에."
- **핵심 문구 3가지:**
  - "2주 완성, 합리적인 정액 패키지"
  - "제작 후 관리까지 대행 — 신경 쓸 일 없습니다"
  - "모바일에서도 완벽하게, 학부모는 대부분 폰으로 검색합니다"
- **CTA 버튼:** "무료 샘플 페이지 받아보기"

## 5. SEO 키워드 리스트 (자사 블로그/사이트 노출용)
| 키워드 유형 | 예시 |
|---|---|
| 핵심 키워드 | 학원 홈페이지 제작, 입시학원 홈페이지 |
| 롱테일 키워드 | 학원 홈페이지 제작 비용, 학원 홈페이지 만들기, 보습학원 홈페이지 후기 |
| 문제 인식형 | 학원 온라인 마케팅 안 하면, 학부모 학원 검색 행동 |

## 6. 콘텐츠 캘린더 (초안 3편)
| 발행 주제 | 목적 | CTA |
|---|---|---|
| "학부모가 학원 검색 후 5초 안에 판단하는 것" | 문제 인식 확산 | 샘플 데모 신청 |
| "학원 홈페이지, 얼마면 만들 수 있을까?" | 가격 반론 해소 | 견적 문의 |
| "경쟁 학원은 이미 시작했다 — 온라인 신뢰도 체크리스트" | 위기감 조성 | 무료 진단 신청 |

## 7. 성과 지표(KPI)
- 아웃리치 메시지 응답률, 샘플 데모 요청 수, 최종 계약 전환율
