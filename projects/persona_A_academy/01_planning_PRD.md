# [기획·디자인 부서] PRD — 페르소나 A 타겟 "학원 홈페이지 스타터 패키지"

**대상 페르소나:** 40대, 원생 150명 규모 보습·입시학원 원장. 현재 네이버 블로그로만 홍보, 자체 홈페이지 없음. "체계가 없어 보인다"는 학부모 피드백을 받은 경험 있음. 경쟁 학원의 홈페이지 개설을 보고 위기감을 느끼는 상태.

## 1. 배경 및 목표
- **비즈니스 목표:** 페르소나 A와 유사한 전국 중형 학원(원생 100~300명 규모)을 대상으로 표준화된 홈페이지 패키지를 빠르게 제안·수주한다.
- **고객 목표:** 학부모가 학원명을 검색했을 때 "체계 있고 신뢰할 수 있는 학원"이라는 인상을 즉시 받도록 한다.
- **성공 지표:** 상담 신청 폼 전환율, 신학기 상담 문의 건수 증가율, 학부모 재등록률.

## 2. 대상 사용자 및 유스케이스
| 사용자 | 유스케이스 |
|---|---|
| 신규 학부모 | 학원 검색 → 커리큘럼/강사진 확인 → 상담 신청 |
| 재원생 학부모 | 공지사항/시간표 확인, 성적·출결 문의 |
| 원장(관리자) | 후기·공지 등록, 상담 신청 목록 확인 |

## 3. 기능 요구사항 (우선순위순)
1. **[Must]** 학원 소개 / 커리큘럼 / 강사진 소개 페이지
2. **[Must]** 상담 신청 폼 (이름/연락처/학년/희망과목 → 관리자 알림)
3. **[Must]** 모바일 반응형 (학부모 대부분 모바일 검색)
4. **[Should]** 학부모 후기 게시판 (신뢰도 구축 핵심 요소)
5. **[Should]** 공지사항/입시정보 게시판 (SEO 콘텐츠 축적용)
6. **[Could]** 온라인 시간표/휴원 안내
7. **[Could]** 카카오톡 채널 연동 버튼

### 완료 조건(Acceptance Criteria) 예시 — 상담 신청 폼
- 필수 항목(이름/연락처) 미입력 시 제출 불가 및 에러 메시지 표시
- 제출 즉시 관리자에게 알림(이메일 또는 카카오 알림톡) 발송
- 모바일에서 원터치로 전화 연결 버튼 병행 제공

## 4. 비기능 요구사항
- 모바일 페이지 로딩 3초 이내(LCP 기준)
- 개인정보(연락처) 수집 시 개인정보처리방침 페이지 필수 게시
- 접근성: 색 대비 WCAG AA 기준 충족

## 5. 범위 제외 사항 (Out of Scope)
- 온라인 결제/원비 자동이체 기능 (1차 패키지에서 제외, 추후 옵션 제안)
- 학생별 개인 성적 조회 시스템 (별도 프로젝트로 분리)

## 6. 사이트맵
```
홈
├─ 학원 소개 (원장 인사말 / 연혁)
├─ 커리큘럼 (과목별 상세)
├─ 강사진 소개
├─ 학부모 후기
├─ 공지사항 · 입시정보
├─ 상담 신청
└─ 오시는 길 / 문의
```

## 7. 일정(WBS) — 표준 2주 패키지
| 단계 | 기간 | 담당 |
|---|---|---|
| 요구사항 확정(PRD 승인) | 1일 | 기획 |
| 와이어프레임/디자인 시안 | 3일 | 기획 |
| 퍼블리싱 · 개발 | 5일 | 기술 |
| 콘텐츠(카피) 삽입 | 병행 2일 | 마케팅 |
| QA 및 최종 검수 | 2일 | 운영 |
| 배포 및 인수인계 | 1일 | 기술·운영 |

- 카카오 알림톡 연동 비용은 별도 옵션 처리 여부 확정 필요
