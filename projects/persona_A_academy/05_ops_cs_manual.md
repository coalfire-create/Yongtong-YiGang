# [고객지원·운영 부서] 페르소나 A 상담 응대 · 검수 매뉴얼

## 1. 인바운드 문의 응대 스크립트

### 시나리오 1 — 마케팅 아웃리치 후 회신 문의
> **학원 원장:** 홈페이지 제작 얼마나 걸리고 얼마예요?
> **응대:** 안녕하세요 원장님! 문의 주셔서 감사합니다 😊 학원 홈페이지 스타터 패키지는 평균 **2주** 안에 완성되고, 커리큘럼·강사소개·후기게시판·상담신청폼이 기본 포함됩니다. 정확한 견적을 위해 원생 규모와 원하시는 기능 몇 가지만 여쭤봐도 될까요?

### 시나리오 2 — 가격 반론 대응
> **학원 원장:** 생각보다 비싸네요, 블로그로도 충분하지 않을까요?
> **응대:** 말씀 충분히 이해합니다. 다만 블로그는 학부모님이 '둘러보는' 용도라면, 홈페이지는 커리큘럼·강사진·후기를 체계적으로 정리해 '등록을 결정'하게 만드는 역할을 합니다. 실제로 2024년 사교육비 시장이 전년 대비 7.7% 성장하며 학부모님들의 학원 비교도 더 꼼꼼해지고 있어요. 부담 없이 샘플 데모부터 먼저 보여드릴까요?

### 시나리오 3 — 제작 후 유지보수 문의
> **학원 원장:** 만들고 나서 내용 수정은 어떻게 하나요?
> **응대:** 월 정액 유지보수 패키지에 콘텐츠 수정 2회가 포함되어 있어, 공지사항이나 시간표 변경은 요청 주시면 저희가 바로 반영해드립니다. 별도로 신경 쓰실 부분은 없습니다.

## 2. SLA (서비스 수준)
| 문의 유형 | 1차 응답 목표 |
|---|---|
| 일반 문의(가격/기간) | 24시간 이내 |
| 견적/계약 관련 | 12시간 이내 |
| 기존 고객 장애/오류 신고 | 2시간 이내 |

## 3. 에스컬레이션 기준
- 기술적 오류(폼 미작동, 사이트 접속 불가) → 즉시 기술 부서로 이관
- 가격 협상/계약 조건 변경 → 대표(COO) 승인 필요
- 콘텐츠(카피) 수정 요청 → 마케팅 부서로 이관

## 4. 최종 산출물 검수 체크리스트 (배포 전 필수)
- [ ] PRD의 모든 Must 기능 정상 동작 확인 (상담신청폼, 반응형, 커리큘럼/강사진 페이지)
- [ ] 모바일·데스크톱·Chrome/Safari/Edge 크로스 브라우저 확인
- [ ] 상담 신청 시 관리자 알림 정상 수신 확인
- [ ] 오탈자·깨진 링크·이미지 누락 여부 확인
- [ ] 개인정보처리방침 페이지 게시 확인
- [ ] 학원명/로고/연락처 등 실제 고객 정보로 교체 완료 확인 (데모 placeholder 잔존 여부 최종 점검)
- [ ] 체크리스트 100% 통과 후에만 고객 인도
